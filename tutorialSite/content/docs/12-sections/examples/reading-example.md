## 内容归文章

作者负责说明、代码和图片。这里使用普通 Markdown。

## 呈现归主题

目录、代码高亮、复制按钮、页面间距和配色由主题提供。

```sh
hugo version
```

从上方面包屑返回“示例分支”，再返回“栏目与 Agent 接入”，体验文章与多层栏目之间的关系。

右侧悬浮目录内点击“浏览栏目”，可看到同级文章和当前所在路径；切回“本页目录”继续定位本文标题。手机点击浮动“目录”按钮后也能操作。没有脚本时两个列表仍能访问。

页面底部的“下一章”通向同栏目的短说明页。本站在此分支通过 readingNav.enabled 启用连续阅读，无需放到 roadmap 目录。
