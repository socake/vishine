# 组件质感打磨与验收清单

更新：2026-10-13。以下按开发轮次保留现场记录，提交／预览状态描述对应当时阶段。外观第二轮、分类缩略图与纯白对比修正已获用户确认，本次按授权发布；实际版本以仓库提交为准。

## 方向与边界

保留原版首页的工作台／跳板定位、板块布局、信息密度和字号。默认配色为第一个选项「暖纸 paper」；访客手动保存的配色继续优先。

配色切换和语言切换分别保留带背景、细边框的独立底槽；选中态与键盘焦点都须清楚可见。顶栏减轻装饰时仍需保留这两组控件的边界，三种配色和手机菜单采用相同的分组原则。
