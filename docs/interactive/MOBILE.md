# 手机呈现与触控验收

2026-10-30。使用实际Hugo生产页面、Ego/Chromium156移动设备模拟，逐尺寸开启并核验pointer:coarse，通过CDP原生触点派发执行点击／滑动。不是实体手机，也不是Safari测试。

## 覆盖与结果

PASS：320×568、360×800、375×812、390×844、430×932、844×390六组尺寸，无整页横向溢出；横竖屏切换保留参数和选择。暖纸、纯白、暗色截图检查，另保留1280px桌面回归截图。

PASS：20项手机交互检查：六尺寸几何、44px有效目标、16px输入文字、单行播放带、GPU选择／详情、通信组切换、数字输入Done、原子应用、旋转、横屏3列、复选文字点按、滑块联动、下一步、放大／适配、播放／暂停、全屏／退出，以及节点列表边界滑动接回文章。

实际修正：

- 复选框原视觉区域24×24px，改为整行label可点且至少44px高，原生checkbox保留。
- 横屏部分图标原32px宽，粗指针统一至少44px宽。
- 数字与选择框原12–14px，粗指针使用16px；step为整数且min≥0的输入提供numeric键盘提示，其余为decimal；done提示配合Enter失焦校验，范围内有效输入仍在编辑时更新。
- 恰好六个数值字段按6／3／2列布局，修复中间宽度5+1排列。
- 图内纵向滚动到边界可继续滚动文章，减少手指停在图上时的滚动隔离。
- 窄屏播放倍率预留92px，避免增大字号后截断；操作带仍为一行。粗指针设备全屏考虑safe-area内边距。

交互对象仍有选中反馈、键盘焦点和说明；不新增依赖，不更改图解计算内容，也未扩大整页字号或修改主题导航。

## 复现与证据

通过ego-browser受管Page调用包内`tests/mobile.browser.mjs`的`run(page, artifactDir, url?)`；默认生产文章URL为localhost:1315/posts/interactive-knowledge-engine/。脚本为每次验收使用不同查询参数，避免读取上次页面；改变尺寸后重新开启触控模拟，防止仅缩小桌面窗口产生错误的“手机通过”结论。

本地忽略目录`.local/mobile-review/`保留mobile-results.json、mobile-geometry.json与八张最终截图。原始审计before.json记录了小目标与输入字号。误把说明必须含“a=”作为滑块断言的测试已修正为验证实际公式值与开口方向，内容原本使用“a>0”。

## 尚未验证／后续优先项

NOT IMPLEMENTED：真实移动网络／低端设备的长期播放、温升、电量与堆内存实验。本轮不声称真机60FPS、不冒充INP数据。上一轮的CPU降速性能口径继续见PERFORMANCE.md。
