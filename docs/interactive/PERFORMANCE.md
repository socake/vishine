# 性能实测与优化边界

2026-10-30；使用实际Hugo生产产物、本机macOS ARM64、Node22.23.1、Ego/Chromium156（10个逻辑核心），浏览器实验开启4倍CPU降速。网络为localhost，未模拟移动网络或实体低端手机。无生产埋点及真实用户INP数据。

## 本轮变化

- 派生值按引用依赖缓存。GPU选择／暂存输入不再每次重建三遍拓扑；模型参数真正变化时才重算。
- 原子事务复用已经验证的计算结果；不可变属性复用校验结果。新增值、非法值和失败回滚继续校验。
- Graph输入不变时跳过重渲染；未播放的实例进出视口不触发刷新。Chart移除重复首次数据更新。
- 构建时按scene.type分派配置校验，复用Schema引用。浏览器仍执行预编译校验，不执行任意代码。
- pagehide不再是一次性监听，经过BFCache恢复后仍能在实际离开时释放实例。

## 前后测量

浏览器连续选择30次，计量为**合成click派发至选中属性DOM提交**，包括本机4倍CPU降速下的处理与React提交；不是完整输入延迟、INP或绘制时间。

- 128 GPU：中位数3.2 → 2.4ms；P95 4.9 → 6.8ms。尾部有波动，不声称所有分位都改善。
- 512 GPU：中位数7.3 → 3.9ms；P95 9.0 → 6.1ms。
- 交互样本内长任务：优化前128GPU样本观察到一个200ms任务，优化后两个规模均未观察到；不能仅据此认定该任务来源，也不保证其他加载／布局阶段没有长任务。

同进程纯计算基准，每类100次；不是浏览器渲染时间：

- 128 GPU选择中位数0.497 → 0.050ms。
- 512 GPU选择中位数1.642 → 0.098ms。
- 512 GPU暂存编辑中位数1.620 → 0.013ms。
- 每100次选择／暂存编辑的GPU模型计算次数300 → 0；验证缓存命中，实际拓扑参数改变仍重算。

100节点链状图首次布局和布线，3次样本中位数34.67 → 32.30ms。改善有限；不代表100节点任意稠密拓扑，不对它承诺60FPS或低端设备无阻塞。

生产JS单文件gzip（不包含CSS／字体）：运行时111,558 → 103,357字节（约减少7.4%）；入口1,276 → 1,272字节。图表约201,830字节、公式78,075字节，仍独立按需加载；GPU浏览中没有请求这两块。普通首页未请求任何knowledge-dist资源。文章接近图解时可能提前请求runtime，进入视口后挂载；不能将有图解文章的资源承诺为零。

## 排除的指标与限制

同次实验记录了两次requestAnimationFrame等待，但受Ego标签可见性／后台调度影响，P95约1秒，不能代表前台绘制或FPS，未用于性能结论。不发布伪INP、60FPS或内存无泄漏保证。清理回归已经执行通过，仅验证释放路径，不是长时间堆内存分析。

本轮未改变布局、控件密度或静态降级策略，也未新增依赖。大规模首次布线、真实移动网络、低端设备、长期内存增长和生产Core Web Vitals仍需后续专门测量。

## 复现

包目录运行`npx tsx tools/benchmark.ts report.json`，产生纯计算及资源体积报告。通过ego-browser受管Page调用`tests/performance.browser.mjs`的`run(page, outputPath)`，实际博客生产站需服务于localhost:1315。它会设置4倍CPU降速并在完成时恢复，测试128／512GPU及普通首页资源，写JSON证据。

同样通过受管Page执行`performance-regressions.mjs`可验证不改图的暂存输入、离屏停止播放以及persisted/non-persisted pagehide清理；后两项为自动化生命周期模拟，不冒充所有浏览器的真实BFCache验收。

本轮原始证据在本地忽略目录`.local/performance/`：before.json、after.json、browser-before.json、browser-after.json和regression。工程测试另覆盖依赖传递、不可变对象、失败候选、步骤回退及缓存隔离。

最终验证：51项核心测试、74项浏览器断言、类型／格式检查、主题检查、生产构建与9份嵌入配置校验通过；现有界面、三套配色、多实例、全屏、键盘与无JS降级回归正常。
