# 固定背景与分层表面

这是主题自动渲染的公共外观能力，默认开启，首页、栏目和文章共用；作者无需添加 shortcode 或修改文章。教程站 `/docs/03-configuration/` 同时展示可复制配置和实际分层效果，exampleSite 的配置显式开启。

## 配置契约

```toml
[params]
  layeredSurfaces = true
```

将该项合并到站点已有的 `[params]`。可选布尔值，默认 `true`；只有布尔 `false` 关闭。不要写成字符串 `"false"`（它不会关闭）。不支持逐页覆盖，无嵌套参数，不依赖 JavaScript 或本地存储。更改后重新构建，开发服务器会重新渲染。

关闭时恢复原有背景、文章边距和卡片表面；搜索、目录、配色与宽度功能仍保留。三种配色共用开关，读者的配色偏好仍优先于 defaultScheme。

## 视觉与行为

| 层次 | 表现 |
| --- | --- |
| 背景 | 固定于视口，不拦截点击；暖纸使用清晰网格与暖光，网格混入原线色的 78%，暗色适当提亮线色；纯白模式使用浅灰 `#f2f3f5` 衬托白色内容面，无网格、无暖色光晕 |
| 内容 | 文章与列表卡片为不透明阅读面，网格不会穿过正文；边界高光与两级投影形成抬升，首页主卡使用板块色标题区聚焦入口 |
| 停靠工具 | 桌面目录使用边界和轻投影的独立纸面；选中项使用强调底色和细竖线，沿用 sticky 和现有宽度按钮；顶栏保持原停靠方式 |
| 浮动操作 | 搜索、菜单、手机目录沿用已有遮罩和浮层顺序，盖在内容之上 |

纯白 `clean` 按中性软件界面定义：浅灰页面衬底、纯白卡片与独立阅读面，边框和投影也使用中性灰，外边缘比内部细分隔线更明显。开启分层时不继承暖纸的棕色阴影；关闭分层时共用同一套颜色 token，文章恢复原来的无独立阅读面布局。

整页沿用浏览器自然滚动。文章无独立纵向滚动容器，没有视差动画或滚动监听；代码和表格仍可以局部横向滚动。桌面为阅读面预留内边距，同时补偿组合宽度；正文与目录作为整体居中，正文目标阅读宽度不变。窄屏使用更小边距与轻阴影，目录按原断点折入浮动入口。

## 维护边界

实现集中在 `assets/css/depth.css`，由主题 CSS 管线统一打包；启用标记由基础模板输出。内部选择器和变量不是作者 API。新增面板应复用现有表面变量，避免给页面外壳添加 transform、固定高度或 overflow 裁切，从而破坏 sticky、浮层和锚点。

验证应覆盖开关两态、暖纸／纯白／暗色、正文与目录宽度往返、搜索遮挡与 Esc、320／390px 回流。固定装饰层不等同于经过性能跑分的 GPU 优化；真实手机表现仍需设备验收。
